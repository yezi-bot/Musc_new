# Channel 门控与历史退回归因分析

## 实验目的

判断跨类别动态实验的性能提升主要来自：

- Channel 门控机制；
- 类别突变期间的最近历史退回；
- 或两者共同作用。

## 对照组

- A：`dynamic_dino_quarantine`，不使用 Channel 门控，不使用最近历史退回。
- B：`dynamic_dino_channel_gate_no_fallback`，使用 Channel 门控，关闭最近历史退回。
- C：`dynamic_dino_channel_gate`，使用 Channel 门控，最近历史退回窗口为 8。

因此，B-A 表示加入 Channel 门控机制后的变化，C-B 表示在完全相同专家时间线下加入最近历史退回后的变化。

每个方向使用 40+40 张图像、3 个随机种子。A、B 为本轮完整运行结果；C 使用此前相同设置的完整结果。审计文件核对显示，B 与 C 在六组实验中的专家时间线和评分状态完全一致，唯一目标差异是退回窗口 0 与 8。

## 三种子均值

### bottle → cable

| 组别 | Image AUROC | 切换后原始 Image AUROC | Pixel AUROC | 切换后 Pixel AUROC | AUPRO |
|---|---:|---:|---:|---:|---:|
| A 无门控、无退回 | 0.7401 | 0.6756 | 0.8427 | 0.7331 | 0.5948 |
| B 有门控、无退回 | 0.8288 | 0.7209 | 0.8617 | 0.7544 | 0.6544 |
| C 有门控、有退回 | 0.9142 | 0.8640 | 0.9082 | 0.8640 | 0.8130 |
| B-A | +0.0887 | +0.0453 | +0.0190 | +0.0213 | +0.0596 |
| C-B | +0.0853 | +0.1431 | +0.0465 | +0.1096 | +0.1586 |

### cable → bottle

| 组别 | Image AUROC | 切换后原始 Image AUROC | Pixel AUROC | 切换后 Pixel AUROC | AUPRO |
|---|---:|---:|---:|---:|---:|
| A 无门控、无退回 | 0.8482 | 0.9444 | 0.9206 | 0.9548 | 0.7693 |
| B 有门控、无退回 | 0.8541 | 0.9389 | 0.9281 | 0.9629 | 0.7982 |
| C 有门控、有退回 | 0.8640 | 0.9156 | 0.9371 | 0.9699 | 0.8309 |
| B-A | +0.0058 | -0.0056 | +0.0076 | +0.0082 | +0.0290 |
| C-B | +0.0099 | -0.0233 | +0.0090 | +0.0070 | +0.0327 |

## 归因结论

1. bottle → cable 的整体 Image AUROC 提升由两部分共同贡献：Channel 门控约 +0.0887，历史退回约 +0.0853，不能把提升只归因于其中一个。
2. bottle → cable 的切换后性能和分割性能主要由历史退回提升；它对切换后原始 Image AUROC、切换后 Pixel AUROC 和 AUPRO 的增益都明显大于门控。
3. cable → bottle 中，门控和退回对整体 Image AUROC 的增益都很小；历史退回虽然提升 Pixel AUROC/AUPRO，却使切换后原始 Image AUROC 平均下降 0.0233。
4. 历史退回不是可靠的类别边界检测器。六组 C 实验中有三组在真实切换前触发过退回：bottle → cable seed 1 为 14 步，cable → bottle seed 1 为 9 步，seed 2 为 6 步。
5. B 与 C 的专家时间线完全一致，因此 C-B 可以确认是评分阶段的最近历史退回造成的，而不是专家准入、删除或确认时间不同。

## 解释边界

B-A 代表完整 Channel 门控方案的贡献，不仅是一个数值阈值：该方案还会在确认前把 provisional 专家用于加权评分，并通过 Channel 支持度完成确认。因此不能把 B-A 表述成“单独改变某个阈值”的效果。

本实验只有两个类别转换方向和三个随机种子，能够说明当前现象的来源，但还不足以证明该结论对所有类别转换都成立。
